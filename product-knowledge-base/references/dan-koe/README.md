## 使用原则

这个目录保存 Dan Koe 的创作者商业、个人品牌、一人公司与 AI 工作流观点。它们是分析视角，不是自动决策规则。

调用时必须：

- 将作者主张、知识库二次分析和真实产品证据分开。
- 将 engagement、traffic、revenue、profit 和 user outcome 分开。
- 检查作者是否同时在推广自己的软件、课程或产品。
- 涉及具体项目时，再用用户研究、支付、留存、成本、合规与交付证据校正。

## 两支影片的关系

第一支更关注创作者如何获得注意、分发、信任和早期产品反馈；第二支在此基础上加入 AI 工作流和收入拆解。合并后可形成：

**用户问题 → 表达与内容 → 分发与信任 → Offer → 收入方程 → AI 加速执行 → 真实反馈 → 迭代**

需要特别防止的误用是：

- 把内容互动当成产品需求。
- 把收入目标拆解当成市场预测。
- 把 AI 生成的客户画像当成真实用户研究。
- 把高总收入当成高利润或健康现金流。
- 把作者的软件演示当成独立的产品效果证据。
