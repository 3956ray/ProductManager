## 测试目的

验证 agent 能否仅依靠本地知识与原始来源回答典型决策问题，并避免把相邻市场、社区声音或 GitHub 热度误写成需求验证。

## Query 1：这个市场是否已经被证明？

**回答**：被证明的是家谱/寻根、故事采集成书和家庭媒体共享三个相邻价值，不是「全家共建编年网页」本身。Ancestry/MyHeritage 提供规模商业信号，Storyworth/Remento/Storii 提供明确结果付费信号，FamilyAlbum 提供家庭网络规模信号；当前产品组合仍是 V1 假设。来源：SRC-01 至 SRC-08。

## Query 2：为什么不直接开发完整平台？

**回答**：家谱、协作、权限、媒体和关系视图已有成熟技术底座，但没有自有证据证明非发起亲属愿意持续贡献或回来浏览。完整平台会先放大技术和维护成本，无法解决核心行为未知项。来源：SRC-11 至 SRC-15；证据缺口见证据地图。

## Query 3：第一版应该卖网页还是书？

**回答**：当前不能决定正式售卖形态。公开证据更清楚支持书册的完成感，网页适合持续浏览、纠正与多视角；最低风险方案是一个第一卷同时提供私密网页和可导出书册，再观察用户真正索取哪一种。来源：SRC-03 至 SRC-10、SRC-16。

## Query 4：AI 应该负责什么？

**回答**：AI 可以转写、整理、提出缺口和生成候选结构，但不能断言亲属关系、合并冲突记忆或虚构历史因果。公开用户声音说明采集负担是真问题，降低输入门槛比自动代写更关键。来源：SRC-04 至 SRC-06、SRC-18、SRC-19。

## Query 5：最优先的产品风险是什么？

**回答**：依次是非发起人不贡献、写作/整理像作业、家庭隐私冲突、平台停止后数据无法导出。公开讨论只能建立风险假设；真正升级到 V2 需要在真实家庭看到主动讲述、纠正、补充、再次浏览或索取成册。来源：SRC-18 至 SRC-20。

## 前向测试结果

- 5/5 回答能回到原始来源编号。
- 5/5 区分相邻市场事实与本产品假设。
- 未把 Reddit 评论、GitHub stars、公司自报或 Research Quality 91 当作需求、购买或留存验证。
- 最大限制是没有独立执行环境中的第二 reviewer；当前结果需要未来用新的未知来源再做一次盲测。
