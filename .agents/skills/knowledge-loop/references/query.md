# Query 协议

1. 先查 `INDEX.md`，再读取相关知识页和其引用的 `SRC-*`。
2. 回答中区分事实、推断、假设和证据缺口，并说明当前 Research Quality 与 Validation Level 对结论的限制。
3. 一次性回答不写回。只有以下内容属于 durable knowledge：
   - 改变或澄清既有决策；
   - 可跨任务复用的事实或框架；
   - 解决反复出现的问题；
   - 形成新的证据缺口或复核触发条件。
4. 用户只要求回答时，给出建议写回位置，不修改文件。获得本地写回授权后才更新 `ideas/`、`references/` 或 `decisions/`。
5. 一次性交付物可进入 `outputs/`，但它不是来源；需要长期保留时，先核验并晋升到正式知识文档。
6. 写回后更新 `INDEX.md`、`LOG.md` 并运行 Lint。
